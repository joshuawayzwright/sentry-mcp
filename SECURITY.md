# Security

This repository mirrors software originating from Sentry's sentry-mcp project.

For vulnerabilities in the upstream Sentry MCP software, follow Sentry's official security reporting process:

https://github.com/getsentry/sentry-mcp/security

Do not publish credentials, access tokens, client secrets, API keys, OAuth secrets, cookie secrets or exploitable vulnerability details in public issues.

For changes unique to this copy, review the difference from the upstream project before reporting so the affected code path can be identified accurately.
